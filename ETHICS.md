# Ethics and Disclosure

This project studies frame-conditioned variation in LLM safety behavior. Testing should use synthetic scenarios, authorized environments, provider-compliant red-teaming practices, and the minimum dangerous detail necessary to evaluate a hypothesis.

Public artifacts should prioritize scientific reproducibility without providing procedural guidance that materially facilitates wrongdoing. Sensitive findings should be disclosed to affected providers before broad publication, with exact model identifiers, reproduction conditions, repetition rates, actionability assessment, and sanitized evidence.

The absence of refusal language is not by itself evidence of a successful jailbreak. Claims should distinguish generic defensive analysis from materially actionable assistance.
