# Contributing

Contributions are welcome when they improve scientific rigor, reproducibility, taxonomy boundaries, evaluation methodology, or defensive mitigations.

Useful contributions include:

- literature references to closely related semantic jailbreak or prompt-manipulation work;
- matched direct/reframed prompt-pair designs that preserve the same information target;
- clean-session and cross-model replication results;
- blinded actionability or harmfulness evaluations;
- proposed falsification tests and ablation studies;
- mitigations that preserve legitimate analytical utility.

Please avoid submitting operationally harmful prompt/output pairs in public issues or pull requests. Use sanitized examples and coordinate privately for sensitive reproductions.
